# 🎟️ Event Ease – College Event Registration & Check-In

**Event Ease** is a web-based application designed to simplify college event management by bringing event creation, participant registration, QR-code generation, and attendance tracking into one platform.

## 🚀 Problem Statement

College event organizers often manage registrations and attendance using disconnected forms and spreadsheets. This can cause duplicate registrations, long queues, and difficulties tracking attendance.

## 💡 Our Solution

Event Ease provides a centralized platform that helps organizers manage college events efficiently and enables students to register and check in easily.

## ✨ Key Features

- 📅 **Event Management:** Create and manage college events.
- 📝 **Online Registration:** Allow participants to register for events.
- 🎫 **QR Code / Entry Code:** Generate unique entry codes for registered participants.
- 📲 **Quick Check-In:** Verify participant registrations at the event entrance.
- 👥 **Participant Management:** View and manage registered attendees.
- 📊 **Attendance Dashboard:** Track registrations and check-in status.
- 🔒 **Data Management:** Store and manage event information securely.
- 📱 **Responsive UI:** Provide a user-friendly experience across devices.

*Features depend on the current implementation of the project.*

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ARJUNSN25/Event-Ease-2.6.git
```

### 2. Open the project folder

```bash
cd Event-Ease-2.6
```

### 3. Install dependencies

If the project contains a `package.json` file, run:

```bash
npm install
```

### 4. Configure environment variables

Create a local `.env` file if required by the project. Add the necessary configuration values using your own credentials and follow the project's setup instructions.

**Never commit secret API keys or passwords to GitHub.**

### 5. Run the application

For a Vite-based React project, run:

```bash
npm run dev
```

Use the local URL printed in the terminal to open the website.

*These commands assume the repository is a Node.js-based frontend project. Backend setup may require additional steps.*
